16 · Ekspor & data
Siklus data

Dari jawaban pengguna menjadi laporan.

1
Pengguna mengirim SDQ

Profil singkat, 25 jawaban mentah, skor terhitung, subskala, dan status disimpan dalam satu transaksi database.

2
Dashboard melakukan agregasi

Sistem menyusun statistik total, demografi, tren bulanan, status, rentang skor, serta rata-rata subskala.

3
Admin menerapkan filter

Filter pencarian, demografi, status, jenis asesmen, rentang tanggal, dan usia dapat digabungkan.

4
Export Excel

File .xls berisi data sesuai filter aktif, termasuk lima subskala dan waktu pengisian.

Langkah ekspor yang disarankan

  • Tentukan tujuan laporan.
  • Terapkan filter yang diperlukan.
  • Periksa jumlah data ditemukan.
  • Tekan tombol Export Excel.
  • Simpan pada lokasi yang aman.
  • Batasi distribusi file.
  • Hapus salinan yang tidak diperlukan.
  • Catat periode dan kriteria ekspor.
!
Ekspor mengikuti filter

Jika admin memfilter gender, status, tanggal, atau usia, file unduhan hanya berisi data yang memenuhi filter tersebut. Gunakan Reset untuk kembali ke seluruh data.

Penghapusan data

Tombol hapus pada detail atau tabel menghapus responden beserta semua jawabannya melalui relasi cascade. Tindakan ini tidak dapat dipulihkan tanpa backup.

18 · Deployment
Operasional

Checklist publikasi dan keamanan dasar.

Struktur cPanel

/home/sipental/ ├── laravel/ # aplikasi, vendor, .env └── public_html/ # index.php dan aset publik

Jalur pada public_html/index.php harus menuju ../laravel/vendor, ../laravel/bootstrap, dan ../laravel/storage.

Permission

TargetMode
Folder umum0755
File umum0644
.env0600/0640
storage & cache0775

Sebelum website dinyatakan siap

  • Backup file dan database lama.
  • Pastikan document root benar.
  • Isi APP_URL dengan domain HTTPS.
  • Isi kredensial database cPanel.
  • Pastikan APP_KEY tersedia.
  • Set APP_DEBUG=false.
  • Pasang API chatbot di server.
  • Bersihkan configuration cache.
  • Uji login dan logout admin.
  • Uji pengiriman kuesioner.
  • Uji export Excel.
  • Periksa log setelah pengujian.
php artisan optimize:clear php artisan migrate --force
!
Jangan pernah membagikan file .env

File tersebut dapat berisi password database dan API key. Jika sebuah key pernah terlihat pada screenshot atau pesan publik, segera cabut dan buat key baru.

Pemecahan masalah

Mulai dari pesan error yang paling spesifik.

GejalaKemungkinan penyebabTindakan
HTTP Error 500Path vendor/autoload.php salah, cache lama, permission, atau konfigurasi.Baca error_log dan storage/logs/laravel.log; perbaiki error pertama yang muncul.
Halaman kosong$app->handleRequest(...) hilang dari index.php.Pastikan front controller lengkap.
Database connection errorNama DB, username, password, host, atau privilege keliru.Cocokkan kredensial cPanel pada .env.
CSS/gambar tidak munculAset tidak berada di document root atau cache browser.Pastikan folder assets ada di public_html, lalu lakukan hard refresh.
Chatbot belum dikonfigurasiAPI key/model belum terbaca oleh Laravel.Periksa variabel server, lalu jalankan optimize:clear.
Chatbot koneksi bermasalahProvider menolak request, kuota, SSL, atau jaringan server.Periksa log Laravel tanpa menampilkan API key.
Grafik admin kosongBelum ada SDQ baru atau library grafik gagal dimuat.Periksa data dan console browser/jaringan CDN.
Impor SQL gagal duplikatDump dimasukkan ke tabel yang sudah berisi data.Backup lalu gunakan database kosong atau lakukan merge terkontrol.

Urutan diagnosis teknis

Catat waktu kejadian → buka log terbaru → baca baris error pertama → cocokkan path/file/konfigurasi → perbaiki satu penyebab → bersihkan cache → uji kembali.

Simpan bukti yang aman
